🚘 Urban Parking

Una solución inteligente para el control de acceso vehicular en ciudades modernas.

🔍 ¿Qué es Urban Parking?

Urban Parking es una plataforma web innovadora diseñada para optimizar el acceso vehicular en parqueaderos urbanos.

Facilita el registro de vehículos, el control de entradas/salidas y mejora la eficiencia operativa a través de una interfaz moderna y segura.

🎯 Objetivo del Proyecto

Digitalizar y modernizar la gestión de parqueaderos, eliminando procesos manuales, minimizando errores y ofreciendo una experiencia más ágil para conductores y administradores.

✨ Características principales

  • ✅ Registro de vehículos con validación
  • ✅ Historial detallado de accesos
  • ✅ Interfaz responsive y fácil de usar
  • ✅ Módulo administrativo con roles (opcional)
  • ✅ Seguridad en el manejo de datos personales

🛠️ Tecnologías utilizadas

  • Frontend: HTML5, CSS3, animaciones, diseño adaptativo
  • Backend: Django (Python)
  • Base de datos: SQLite (modo desarrollo) / PostgreSQL (modo producción)

👥 Autores del Proyecto

Este sistema fue desarrollado por un equipo de estudiantes y desarrolladores con el propósito de resolver un problema real en la gestión de parqueaderos urbanos.

El proyecto refleja una combinación de habilidades técnicas, creatividad y compromiso con la mejora urbana.
